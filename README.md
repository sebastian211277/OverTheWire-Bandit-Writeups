# OverTheWire: Bandit - Security Write-ups & Automation

## 🎯 Objective
This repository contains my personal write-ups and solutions for the first 34 levels (0-33) of the [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) wargame. 

Rather than just listing the passwords, the focus of this project is to document the **methodology, underlying Linux concepts, and automation**. As a software developer transitioning into cybersecurity, I have included custom scripts (Bash/Python) to automate repetitive tasks and demonstrate an engineering approach to security challenges.

## 🛠️ Tools & Technologies Used
* **OS:** Linux CLI (Bash scripting, piping, redirection)
* **Networking:** SSH, SCP, Netcat, Nmap
* **Automation:** Python, Bash
* **Concepts:** File permissions (SUID/SGID), Cronjobs, Git, Text manipulation (awk, sed, grep)
